# Smart Assistant

دستیار هوشمند اندرویدی با قابلیت تعامل متنی و صوتی، اجرای فرمان‌ها و توسعه قابلیت‌های هوشمند.

## هدف پروژه

ساخت یک دستیار شخصی هوشمند که به‌مرور بتواند:

* با کاربر به‌صورت صوتی و متنی تعامل کند
* فرمان‌های کاربر را اجرا کند
* به سرویس‌های هوش مصنوعی متصل شود
* قابلیت‌های گوشی را مدیریت کند
* قابلیت‌های جدید را به‌صورت ماژولار دریافت کند
